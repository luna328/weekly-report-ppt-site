# Weekly Report PPT Archive

This repository hosts weekly HTML slide decks.

## Structure

```text
.
├── index.html
└── reports/
    └── week-01/
        ├── index.html
        └── assets/
            └── motion.min.js
    └── week-02/
        ├── index.html
        └── assets/
            └── motion.min.js
```

## Deploy

Use any static hosting provider:

- Netlify
- Cloudflare Pages
- GitHub Pages
- Vercel

For Netlify or Cloudflare Pages, connect this GitHub repository and set the publish directory to the repository root.
